# **App Name**: Base Text Display

## Core Features:

- Text Display: Display the text 'c-life-coach base text' on the screen.

## Style Guidelines:

- Primary color: A calming blue (#64B5F6) to promote focus and clarity.
- Background color: A light gray (#F0F0F0), providing a neutral backdrop that is easy on the eyes.
- Accent color: A muted teal (#4DB6AC) for subtle highlights and interactive elements.
- Body and headline font: 'Inter' sans-serif font, known for its readability and modern appearance.
- The text is centrally aligned and given generous padding to avoid any crowding on smaller screens.
